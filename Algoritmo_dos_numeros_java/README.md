# ALGORITMOS DOS NÚMEROS EM JAVA
* Fundamentos matemáticos, implementação em Java e aplicações em criptografia assimétrica
# Objectivos
## Objetivo Geral
Desenvolver um estudo teórico-prático sobre algoritmos dos números, explorando os seus funda
## Objetivos Específicos

- Compreender conceitos de teoria dos números.
- Implementar o Algoritmo de Euclides e cálculo do MDC.
- Estudar números primos e factorização de inteiros.
- Aplicar aritmética modular e congruências.
- Implementar a Função Totiente de Euler.
- Desenvolver uma versão didática do sistema RSA.
- Realizar testes de primalidade.
- Analisar a relação entre teoria dos números e segurança informática.
## Como executar
Abrir Main.java e clicar em Run.
