# Descrição do Projecto

## Algoritmos dos Números com Implementação em Java

#Introdução

A teoria dos números é um dos ramos mais importantes da Matemática Discreta e possui aplicações fundamentais na Computação, principalmente nas áreas de criptografia, segurança informática, algoritmos e sistemas computacionais.
O presente projecto foi desenvolvido no âmbito da disciplina de Algoritmo e Estrutura de Dados II, com o objectivo de estudar, analisar e implementar algoritmos matemáticos relacionados com a teoria dos números utilizando a linguagem de programação Java.
Os algoritmos implementados demonstram conceitos matemáticos importantes como:
- máximo divisor comum,
- números primos,
- congruências,
- aritmética modular,
- Totiente de Euler,
- criptografia RSA,
  entre outros.

O trabalho possui natureza teórico-prática, combinando fundamentos matemáticos com implementação computacional em aplicações de consola.

#  Algoritmos Implementados

## Máximo Divisor Comum

Implementamos o cálculo do MDC utilizando método simples baseado na procura de divisores comuns.

## Algoritmo de Euclides

Para cálculo do MDC utilizamos divisões sucessivas.

## Teste de Primalidade

Verificação de números primos utilizando optimização baseada na raiz quadrada do número.

## Factorização de Inteiros
Decomposição de números inteiros em factores primos.

## Congruências

Implementação de operações de aritmética modular e verificação de congruências.

## Pequeno Teorema de Fermat

Aplicação do teorema em operações modulares envolvendo números primos.

## 6.7 Teorema Chinês do Resto

Resolução de sistemas simples de congruências.

## 6.8 Totiente de Euler

Cálculo da função φ(n) utilizando coprimalidade e o Algoritmo de Euclides.

## Sistema RSA

Implementação de criptografia assimétrica utilizando:
- geração de chaves,
- cifragem,
- decifragem

O RSA é um dos sistemas criptográficos mais utilizados no mundo moderno.
A sua segurança baseia-se na dificuldade computacional da factorização de números inteiros muito grandes em factores primos.
O sistema RSA é amplamente utilizado em:
- segurança informática,
- comunicações seguras,
- comércio electrónico,
- autenticação digital.
